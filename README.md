# أرشيف أكتوبر — متحف رقمي تعليمي

موقع عربي ثابت (HTML / CSS / JavaScript) لعرض حرب أكتوبر 1973، مبني على محاور البحث المرفق «حرب السادس من أكتوبر.pdf» مع أقسام للخط الزمني، والملفات التحليلية، ومعرض الصور، والفيديوهات، والكتب، والمصادر.

## التشغيل

1. فك ضغط الملف.
2. افتح `index.html` في المتصفح.
3. يحتاج الموقع إلى اتصال بالإنترنت لتحميل صور Wikimedia Commons والخطوط من Google Fonts. التصميم الأساسي يعمل حتى دون الخطوط الخارجية، لكن الصور الخارجية لن تظهر دون الإنترنت.
4. للنشر، يمكن رفع المجلد كاملًا إلى GitHub Pages أو Netlify أو Vercel كصفحة ثابتة؛ لا يحتاج إلى Python أو قاعدة بيانات.

## إضافة فيديو يوتيوب

1. افتح `videos.html` في محرر الكود.
2. ابحث عن البطاقة المطلوبة، مثل:
   `<article class="card video-card ..." data-category="doc" data-youtube-id="">`
3. ضع معرّف الفيديو بين علامتي الاقتباس في `data-youtube-id`. معرّف الفيديو هو الجزء الذي يأتي بعد `v=` في رابط يوتيوب؛ مثال توضيحي فقط: إذا كان الرابط `https://www.youtube.com/watch?v=ABC123XYZ00` فالمعرّف هو `ABC123XYZ00`.
4. غيّر عنوان البطاقة ووصفها والجهة الناشرة لتطابق الفيديو الفعلي. المشغل سيظهر تلقائيًا.

## إضافة صورة

أضف بطاقة داخل `.gallery-grid` في `gallery.html`، وضع رابط الصورة في `src` و`data-full`، ثم أضف رابط صفحة الملف الأصلية في رابط «بيانات الصورة والترخيص». لا تستخدم صورة دون مراجعة شروط إعادة الاستخدام أو ذكر الإسناد المناسب.

## إضافة كتاب

انسخ بطاقة من `books.html`، وعدّل العنوان والمؤلف والوصف وكلمات البحث في `data-search`، ثم ضع رابطًا موثوقًا للفهرس أو الناشر. روابط Google Books الحالية هي روابط بحث للعناوين، وليست تأكيدًا لتوفر طبعة معينة.

## بنية الملفات

- `index.html` — الصفحة الرئيسية والمشهد الثلاثي الأبعاد التفاعلي.
- `timeline.html` — الخط الزمني مع فلاتر قبل الحرب/أيام الحرب/ما بعد الحرب.
- `chapters.html` — التخطيط والخداع والحرب النفسية والتجسس والجيل الخامس والأمن السيبراني والقوة الناعمة.
- `gallery.html` — الصور التاريخية مع بيانات المصدر والترخيص، ونافذة تكبير.
- `videos.html` — مساحات فيديو جاهزة لإضافة YouTube IDs.
- `books.html` — الكتب وفهرس بحث تفاعلي.
- `sources.html` — الوثائق والمراجع ومنهجية التحقق.
- `styles.css` و`app.js` — التصميم والسلوك التفاعلي.

## ملاحظات تحريرية

- المشهد الثلاثي الأبعاد في الرئيسية نموذج تعليمي تخطيطي، وليس خريطة عسكرية دقيقة أو إعادة بناء معتمدة للعمليات.
- صور المعرض تُحمّل مباشرة من Wikimedia Commons؛ افتح صفحة كل صورة لمراجعة معلومات الترخيص والمصدر قبل إعادة استخدامها في مشروع آخر.
- المحاور السبعة مأخوذة من البحث المرفق. بعض الادعاءات التفصيلية الواردة في البحث تحتاج إلى إسناد مستقل قبل عرضها كوقائع نهائية؛ لذلك أُضيفت ملاحظات واضحة حول التحقق من الروايات والأرقام.
- لا تُعد روابط البحث في المكتبة بديلًا عن استكمال بيانات الطبعة: المؤلف، والعنوان، ودار النشر، والسنة، ورقم الصفحة.
